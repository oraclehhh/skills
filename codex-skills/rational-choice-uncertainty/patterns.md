# Patterns

## Base-Rate First

**When to use**: diagnosing, forecasting, hiring, investing, or estimating rare events.

**How**:
1. Define the reference class.
2. Find the base rate before reading case details.
3. Add case-specific evidence only if it is diagnostic.
4. Express the final judgment as a range.

**Trade-offs**: protects against vivid stories but depends on choosing a relevant reference class.

## Anchor Removal

**When to use**: negotiation, pricing, planning, forecasting, performance evaluation.

**How**:
1. Hide or bracket the anchor if possible.
2. Generate an independent estimate.
3. Compare with multiple reference classes.
4. Ask what evidence justifies moving toward the anchor.

**Trade-offs**: slows quick estimates but improves calibration.

## Cue-Weight Audit

**When to use**: expert judgment, scoring rubrics, admissions, hiring, risk assessment.

**How**:
1. List cues available to the judge.
2. Estimate each cue's actual validity.
3. Estimate how much the judge uses each cue.
4. Reduce reliance on salient but weak cues.
5. Use a simple linear model as baseline.

**Trade-offs**: may feel reductive; often improves consistency.

## Rival Story Test

**When to use**: legal reasoning, incident reviews, strategy, medicine, interpersonal conflict.

**How**:
1. State the favored story.
2. Generate at least two rival stories.
3. Identify evidence each story predicts.
4. Search for disconfirming evidence.
5. Delay confidence until alternatives have been compared.

**Trade-offs**: reduces narrative overconfidence but requires disciplined effort.

## Natural Frequency Conversion

**When to use**: medical tests, risk communication, conditional probability.

**How**:
1. Pick a population size such as 1,000.
2. Apply prevalence first.
3. Apply sensitivity to actual positives.
4. Apply false-positive rate to actual negatives.
5. Compute the proportion among positive tests.

**Trade-offs**: more verbose than percentages; much clearer for humans.

## Sunk-Cost Reset

**When to use**: projects, relationships, investments, subscriptions, strategic commitments.

**How**:
1. Remove past unrecoverable costs from the evaluation.
2. Ask what you would choose if starting today.
3. Compare only future costs, benefits, risks, and opportunity costs.
4. Decide whether continuation is still the best forward-looking option.

**Trade-offs**: emotionally hard; normatively clean.

## Robust Decision Tree

**When to use**: uncertain high-stakes decisions.

**How**:
1. Draw actions first.
2. Add uncertain events in time order.
3. Estimate probabilities and utilities.
4. Compute expected utility.
5. Change inputs across plausible ranges.
6. Prefer decisions that remain good under estimation error.

**Trade-offs**: exposes assumptions; can create false precision if numbers are invented carelessly.
