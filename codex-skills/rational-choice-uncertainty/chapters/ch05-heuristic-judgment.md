# Chapter 5: 启发式判断

## Core Idea

启发式是快速而有用的判断捷径，但当心理上的易得性、相似性或想象性与真实概率脱节时，它们会系统性地误导判断。

## Frameworks Introduced

- **Availability Heuristic**: ease of recall becomes a proxy for likelihood.
- **Representativeness Heuristic**: similarity to a prototype becomes a proxy for probability.
- **Base-Rate Check**: start with the prevalence of the category before individuating evidence.

## Key Concepts

- **Heuristic**: simple rule or process that reduces cognitive effort.
- **Base-rate neglect**: underweighting prior probabilities.
- **Conjunction error**: judging a detailed combined event as more likely than a broader event.

## Mental Models

Use "feels frequent" versus "is frequent." If a judgment is powered by memory fluency, demand a count, denominator, or reference class.

## Anti-patterns

- **Prototype substitution**: answering "How similar is this?" when the real question is "How likely is this?"
- **Media-frequency inference**: treating covered events as common events.

## Worked Example

If a startup failure story is memorable, availability may make the entire category feel doomed. A better judgment asks for the base failure rate, relevant cohort, funding stage, market conditions, and whether the case is representative.

## Key Takeaways

1. Heuristics are useful but need boundary checks.
2. Base rates are the first defense against representativeness.
3. Vivid evidence should be weighted by diagnostic value, not memorability.
