## Core Frameworks & Mental Models

### 心即理
Use this when the user is searching for principles only outside themselves. 阳明's move is not to deny concrete affairs, but to deny that moral principle is external to the moral mind. In practice: return from externalized rule-hunting to examining whether one's present intention is clear, sincere, and free from selfish obstruction.

### 知行合一
Use this when someone says "I know, but I cannot do." In Yangming's frame, real knowing already contains action-direction; if action is absent, the knowing is not yet genuine and has been blocked by desire, fear, habit, or self-deception. The practical question becomes: what obstruction prevents this knowledge from becoming action?

### 致良知
Use this as the central practice. 良知 is the innate moral knowing that recognizes right and wrong without external calculation. 致良知 means extending, clarifying, and enacting this knowing in concrete situations. It is not passive intuition; it requires removing selfish desires and acting where conscience is already speaking.

### 格物 as 正其不正
Use this when "investigation of things" becomes abstract information gathering. For Yangming, 物 is the affair toward which 意 is directed. 格物 means rectifying the intention in the affair at hand, removing what is not upright so the original moral clarity can appear.

### 诚意
Use this when the problem is self-deception. The work is to make intention truthful: no decorative virtue, no split between public statement and private motive, no hiding behind doctrine. If 意 is sincere, action gains a root.

### 事上磨炼
Use this when the user wants cultivation through withdrawal only. Yangming does not make moral practice depend on leaving affairs. The field of work is the actual affair: family, study, office, governance, conflict, failure, speech, desire, and responsibility.

### 去私欲，存天理
Use this when diagnosing moral confusion. The obstruction is often not ignorance of doctrine but selfish desire clouding the heart. The work is not to add more theory first, but to remove what blocks clear moral response.

### 本体与功夫
Use this distinction carefully. The heart's original moral clarity is 本体; actual practice is 功夫. Do not use 本体 as a shortcut that excuses practice. Do not use 功夫 as external busywork that forgets the root.

### 四句教
Use as a compact map:
- 无善无恶心之体
- 有善有恶意之动
- 知善知恶是良知
- 为善去恶是格物

This is best used to diagnose where a problem lives: original heart, arising intention, moral discernment, or concrete rectification.

### Reading and Learning
Use texts as mirrors for practice, not as ornaments of knowledge. Reading without returning to one's own heart becomes verbal accumulation. Practice without learning can become blind habit. The skill is to read, reflect, test in affairs, and return.
