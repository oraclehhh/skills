# Cheatsheet: 阳明心学应用

## Fast Diagnosis

| Situation | Use | Ask |
|---|---|---|
| "我知道但做不到" | 知行合一 | 这是真的知道，还是被私欲/恐惧/习气隔断了？ |
| 到处找外部标准 | 心即理 | 我此刻的本心是否已知此事的正当方向？ |
| 学很多但不改变 | 诚意 / 读书法 | 我读书是在修身，还是在装饰知识？ |
| 遇事就乱 | 事上磨炼 | 这件事正好要求我在哪个念头上用功？ |
| 道德判断模糊 | 致良知 | 良知已经指出什么？我在回避什么？ |
| 把格物当查资料 | 格物 | 我的意念落在哪件事上？其中不正处是什么？ |
| 空谈本体 | 本体与功夫 | 这个见解如何落实为去私欲、为善去恶？ |

## Four-Step Practice

1. **定事**: name the concrete affair, not an abstract mood.
2. **察意**: identify the intention active in this affair.
3. **辨知**: ask what 良知 already knows as right or wrong.
4. **格物**: remove the crooked intention and enact the right action.

## Four-Sentence Map

| Line | Use |
|---|---|
| 无善无恶心之体 | Do not confuse original heart with passing desires |
| 有善有恶意之动 | Moral problem appears when intention moves |
| 知善知恶是良知 | Discernment is already present as moral knowing |
| 为善去恶是格物 | Practice means rectifying the concrete affair |

## Study Rule

Read a passage, then ask:
- What concrete affair does this illuminate?
- What selfish desire does it expose?
- What action would prove I understand it?
- What would be mere verbal knowledge here?

## Anti-Self-Deception Checks

| Claim | Check |
|---|---|
| "我只是还没准备好" | Is preparation becoming avoidance? |
| "我需要更多理论" | Is the next right action already clear? |
| "这是环境问题" | What part of my intention is still mine to rectify? |
| "我在修心，所以不管事" | Is this withdrawal or genuine clarity? |
| "我已经懂了" | Where has this understanding changed conduct? |
