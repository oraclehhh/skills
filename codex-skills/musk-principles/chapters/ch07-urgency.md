# Chapter 7: 疯狂的紧迫感

## Core Idea
速度既是进攻也是防守。紧迫感通过压缩时间、并行推进和拆解“不可能”来暴露真实瓶颈。

## Frameworks Introduced
- **Speed as Strategy**: fast cycles create learning and competitive advantage.
- **Parallel Execution**: run multiple independent paths when time matters.
- **Impossible Decomposition**: split impossible goals into smaller constraints.
- **Schedule Compression**: use aggressive timelines to reveal waste.

## Key Concepts
- **Cycle time**: duration from idea to feedback.
- **Parallel path**: simultaneous work stream.
- **Bottleneck**: constraint limiting system throughput.

## Mental Models
Use "time pressure as diagnostic." If compression breaks the plan, the break shows where the system was weak.

## Anti-patterns
- **Sequential waiting**: delaying all work until one uncertain item resolves.
- **Urgency without priorities**: making everything important and exhausting the team.

## Worked Example
For a product launch, run design, supplier validation, tooling, test plans, and customer feedback in overlapping loops instead of strict sequence.

## Key Takeaways
1. Speed creates more contact with reality.
2. Parallel work beats passive waiting.
3. Urgency must be focused on the mission-critical path.
