# Chapter 1: 明确人生目标

## Core Idea
目标不是口号，而是筛选人生和工作的操作系统。优先选择对人类、客户或未来有用的事，而不是仅仅体面、舒适或能带来声望的事。

## Frameworks Introduced
- **Useful Work**: choose work by contribution, not vanity.
- **Contribution > Consumption**: aim to create more value than you consume.
- **Fear-Facing Purpose**: large goals require acting despite fear and uncertainty.

## Key Concepts
- **Purpose**: a durable direction that selects actions.
- **Usefulness**: real-world contribution beyond self-display.
- **Disruptive innovation**: creating paths that change what is possible.

## Mental Models
Use a "deathbed filter": would you still respect this work if reputation, applause, and comfort disappeared?

## Anti-patterns
- **Status-first career design**: optimizing for admiration instead of impact.
- **Comfortable drift**: letting inherited norms decide your path.

## Worked Example
A founder deciding between a fashionable app and a hard energy project should ask which path creates more durable human benefit, not which one is easier to pitch.

## Key Takeaways
1. Purpose should change priorities, not merely mood.
2. Useful work is the central measure.
3. Big missions make hardship meaningful.
