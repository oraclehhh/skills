# Chapter 4: 基本判断策略：锚定与调整

## Core Idea

人们常从一个初始值出发进行调整，但调整通常不足。锚可以来自先前信息、默认值、谈判报价、随机数字或自己刚生成的估计。

## Frameworks Introduced

- **Anchoring and Adjustment**: estimate from an initial reference point, then adjust.
- **Weighted Averaging**: judgments often integrate new evidence by shifting from an anchor rather than recomputing.
- **Independent Estimate Rule**: generate a private estimate before seeing external anchors.

## Key Concepts

- **Anchor**: the initial value or reference point.
- **Adjustment**: movement away from the anchor in response to evidence.
- **Insufficient adjustment**: stopping too close to the anchor.

## Mental Models

Treat every visible number as a force field. Ask whether the final estimate has independent justification or is merely near the first number encountered.

## Anti-patterns

- **Negotiating from the other side's number**: accepting their anchor as the center of discussion.
- **Planning from desired dates**: using a target date as the anchor rather than historical completion rates.

## Worked Example

Before estimating a project timeline, write an estimate from similar completed projects. Only then compare with the proposed deadline. If adjustment from the proposed deadline dominates the outside-view estimate, anchoring is likely active.

## Key Takeaways

1. Anchors work even when arbitrary.
2. Adjustment is usually too small.
3. Use outside-view data and independent estimates to weaken anchors.
